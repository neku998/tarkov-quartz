## 🎯 The Aim Build

Tuned for crosshair control, with conservative defaults.

| **Parameter** | **Default** | **Range** |
| --- | --- | --- |
| Field of view | 12° | 4–180° |
| Smoothing | 52 | 1–100 |
| Target bone | chest | chest / neck / head |
| Visibility gate | on | on / off |
| Reaction delay | 120 ms | 0–400 ms |
| Trigger assist | off | off / tap / hold |

**The one setting that matters**

Smoothing. Every other value changes how the aim performs; smoothing changes how
it *looks*. A crosshair that arrives in one frame is not something a hand does.
Spreading the travel across 8–15 frames is what makes the movement read as human,
and it costs you almost nothing in actual accuracy.

**Recommended order of tuning**

1. Set the **target bone** to chest. Leave it there until you are comfortable.
2. Set **reaction delay** to ~120 ms. Instant acquisition is the loudest tell.
3. Widen **FOV** only after you find yourself genuinely missing.
4. Touch **smoothing** last, and only downward.
5. Enable the **visibility gate** before any competitive mode.

**The setting people get wrong**

Wide FOV with low smoothing. That combination is the most visible configuration in
the entire pack — the crosshair visibly jumps across the screen. If you change one
number for safety, change FOV.

**Included alongside**

The overlay, the config system and the loader are all present; this build simply
ships with aim-friendly presets preloaded.

**Order of operations**

1. Close the game and its launcher completely.
2. Run the loader as administrator.
3. Open the **Spoofer** tab and press **Spoof**.
4. **Reboot** — volume serial and SMBIOS are read at boot.
5. Create a fresh account and log in.

**What it does not do**

It does not unban the old account. It gives the machine a new identity so a new
account is not linked to the old ban.

**Skipping the reboot is the most common mistake** — people report "the spoofer
did nothing" when they simply never restarted.
